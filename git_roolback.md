Способ отката зависит от того, что именно вы хотите сделать: удалить только ошибочный тег v1.6.0 или полностью отменить последний коммит на GitHub.
Ниже описаны решения для обоих сценариев.

# Вариант 1: Нужно удалить только тег v1.6.0 (код остается)

Если сам код верный, но вы ошиблись с версией, удалите тег на компьютере и на GitHub.
Выполните в терминале:
```bash
# 1. Удаляем тег локально
git tag -d v1.6.0

# 2. Удаляем тег с GitHub
git push origin --delete v1.6.0
```
Используйте код с осторожностью.

# Вариант 2: Безопасный откат коммита (Рекомендуется)

Этот способ создает новый коммит, который выворачивает наизнанку (отменяет) изменения предыдущего коммита. История проекта при этом не ломается.
```bash
# 1. Отменяем последний коммит локально (создастся новый коммит-отмена)
git revert HEAD --no-edit

# 2. Отправляем изменения на GitHub в ветку master
git push origin master
```
Используйте код с осторожностью.

# Вариант 3: Полное удаление последнего коммита (Внимание: стирает историю!)

Если вы хотите полностью стереть последний коммит с GitHub, как будто его никогда не было. Используйте осторожно, особенно если над проектом работает кто-то еще.
```bash
# 1. Откатываем ветку на один коммит назад локально (файлы останутся измененными)
git reset --soft HEAD~1

# 2. Принудительно обновляем GitHub (флаг --force)
git push origin master --force
```
Используйте код с осторожностью.
Если нужно не просто отменить коммит, а полностью уничтожить все изменения в файлах, замените --soft на --hard в первой команде.

# Запушить новую версию
```bash
git add .
git commit -m "Релиз версии v1.6.0"
git tag -a v1.6.0 -m "Версия v1.6.0"
git push origin master --tags
```
